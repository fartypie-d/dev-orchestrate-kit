# Task 7: 호스트 전용 라이브 인프라 경고 일반화 (chrome-cdp)

- **에이전트**: kit-docs
- **모델**: default
- **대상 파일**: `CLAUDE.md`, `.claude/orchestrate.md`
- **선행**: 없음
- **목표**: 개발 호스트 전용 규칙("`/opt/chrome-cdp` 컨테이너 — 다른 사용자의 CDP 세션이 살아 있다")이
  범용 키트에 그대로 배포되어, 새 호스트에서 하네스가 브라우저 작업을 통째로 거부한다(클린 호스트 실측).
  소유·상태 조건부 문구로 일반화한다.
- **재사용**: 개선 후 재사용 `CLAUDE.md:66` · `.claude/orchestrate.md:90` 해당 행 (다른 절 변경 금지)
- **실패 테스트**: 불가 사유 — markdown 문서. 대체 검증: `grep -rn "opt/chrome-cdp" CLAUDE.md .claude/` 로
  무조건 금지 문구가 사라졌는지 확인 + 리뷰어 검수
- **필수 규칙**:
  - 대체 문구 취지: "**자기 소유가 아니거나 이미 운영 중인** 라이브 CDP 컨테이너·세션은 조작 금지.
    이 킷의 `containers/browser` 번들을 본인이 띄운 경우는 해당 없음." (`/opt/chrome-cdp`는 예시로만,
    무조건 금지 대상으로 쓰지 않는다)
  - `~/.claude`·`~/.config` 실홈 보호 문구(같은 절)는 유지한다 — 테스트 임시 디렉터리 규칙은 범용으로 유효.
  - `docs/specs/`·`docs/plans/`의 과거 설계 기록은 건드리지 않는다 (히스토리).
- **완료 조건**: 두 파일에서 무조건 금지 문구 제거 확인(grep) + 전체 unittest GREEN (문서 변경이라 영향 없음 확인)
